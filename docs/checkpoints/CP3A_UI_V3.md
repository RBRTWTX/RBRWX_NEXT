# CP3A UI V3 — restore operator transport

Corrects V2's overbroad removal of playback controls. Previous/play/next controls
beside TAKE and the adjacent weather step/play/loop/refresh controls are restored.
The unwanted exposed playback strip beside the title stays removed.

The hidden menu retains weather controls and its Rundown section. Rundown now
also includes TAKE PREVIEW and SHOW LOOP with proper disabled play state. Menu
buttons are constrained to the panel at Windows display scaling.

V2's editable title/time/keys, corner scaling, optional subtitle, and removed
bottom source bar are preserved. No data adapter or expiry behavior changes.
